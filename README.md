# Lost and Found Application

A web-based Lost and Found application that allows users to register, login, report lost items, report found items, and view reported items.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- GitHub
- Jenkins

## Features

- User Registration
- User Login
- Report Lost Items
- Report Found Items
- View Lost and Found Items
- Backend API
- Automated Testing
